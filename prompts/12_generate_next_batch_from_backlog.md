# 12 - Backlog'dan Siradaki Batch'i Uretme Promptu

Sen Claude olarak proje beyni rolundesin. Bu prompt, backlog-driven batch sisteminde yalnizca `BATCH_CURSOR.md` icindeki 3 dersi uretmek icindir.

Once oku:

1. `PROJECT_CONTEXT.md`
2. `AI_HANDOFF.md`
3. `DECISIONS.md`
4. `LESSON_TEMPLATE.md`
5. `VISUAL_ANIMATION_SYSTEM.md`
6. `INTERVIEW_SYSTEM.md`
7. `CURRICULUM_LESSON_BACKLOG.md`
8. `BATCH_CURSOR.md`

## Gorev

`BATCH_CURSOR.md` icindeki `Next batch` dersleri icin final content candidate uret.

Batch disina cikma. Backlog'daki diger dersleri yalnizca baglam olarak oku; onlar icin icerik, baslik genisletmesi, metafor veya prototip talimati uretme.

## Zorunlu Kurallar

- `PROJECT_CONTEXT.md` tek dogruluk kaynagidir.
- Sadece `BATCH_CURSOR.md` icindeki 3 ders islenir.
- Her ders `LESSON_TEMPLATE.md` v0.3.1'e uyar.
- D30 zorunludur: cognitive accessibility is not content simplification; it is progressive depth design.
- Her ders icin Depth Ladder zorunludur.
- Her dersin gorsel metaforu konuya ozel olmalidir; jenerik diyagram yok.
- Visual Mode adim kontrollu olmalidir.
- Code Mode kisa Java ornegi ve visual-code sync map icermelidir.
- Micro-assessment ve soft-check bulunmalidir; hard-lock yok.
- Interview Mode ezber degil, muhakeme sirasi vermelidir.
- Tam mufredat uretme.
- Cursor disi ders uretme.
- Cikti Turkce olmali; teknik terimler English kalabilir.

## Cikti

1. Batch ID listesi
