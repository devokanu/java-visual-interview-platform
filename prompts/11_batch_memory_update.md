# 11 - Batch Memory Update Promptu

Sen Codex GPT-5.5 veya Claude olarak batch tamamlandiktan sonra proje hafizasini guncelliyorsun.

Once oku:

1. `PROJECT_CONTEXT.md`
2. `AI_HANDOFF.md`
3. `DECISIONS.md`
4. Batch issue raporu
5. Batch review / QA raporu

## Gorev

Batch tamamlandiginda proje hafizasina yalnizca kisa, izlenebilir progress notlari ekle.

## Kurallar

- `PROJECT_CONTEXT.md` tek dogruluk kaynagidir.
- `PROJECT_CONTEXT.md` Current Progress bolumunu guncelle.
- `AI_HANDOFF.md` Tamamlananlar ve Mevcut Gorev bolumlerini kisa tut.
- `DECISIONS.md` yalnizca gercek, kalici bir karar varsa guncellenir.
- Vite + React veya Vercel gibi prototip araclarini final karar gibi yazma.
- Yeni lesson content'i bu prompt ile uretme.
- App kodu degistirme.

## Eklenebilecek Not Ornekleri

- "M__ lesson batch final content candidates accepted."
- "M__ lesson batch integrated into prototype."
- "Batch QA passed; mobile/device test pending."
- "Batch lesson factory workflow scaffolding created."

## Cikti

Turkce rapor ver:

1. Guncellenen memory dosyalari
2. Eklenen progress notlari
3. DECISIONS.md degisti mi?
4. App kodu degisti mi?
5. Siradaki onerilen adim
