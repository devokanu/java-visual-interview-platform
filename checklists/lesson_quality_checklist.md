# Lesson Quality Checklist

Tek ders için hızlı kalite kontrolü.

- [ ] Ders tek bir hedef cümlesine sahip.
- [ ] Önce somut benzetme, sonra teknik kavram geliyor.
- [ ] Her teknik terim ilk geçişte basit Türkçe açıklanıyor.
- [ ] Tek seferde tek fikir korunuyor.
- [ ] LESSON_TEMPLATE ana bölümleri mevcut.
- [ ] Theory / Visual / Code / Interview ayrımı net.
- [ ] Micro-assessment kısa ve tek kavram ölçüyor.
- [ ] Soft-check var; hard-lock yok.
- [ ] Rescue flow nazik ve görünür.
- [ ] Üretim örneği gerçekçi.
- [ ] Debugging / trade-off bölümü hedef seviyeye katkı veriyor.
- [ ] Interview cevabı ezber değil düşünce sırası veriyor.
- [ ] D30 korunuyor: erişilebilirlik sığlaştırma değil, progressive depth.
- [ ] Tam müfredat veya ekstra ders üretilmemiş.
