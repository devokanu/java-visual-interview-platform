# Batch Lesson Quality Checklist

3 derslik lesson batch icin kalite kontrol listesi.

## Batch Siniri

- [ ] Batch tam olarak 3 ders iceriyor.
- [ ] Batch disinda yeni ders uretilmedi.
- [ ] Tam mufredat dokulmedi.
- [ ] Her dersin onceki ve sonraki baglantisi net.

## D30 / Progressive Depth

- [ ] Her ders basit giris + derinlesme yolu dengesini koruyor.
- [ ] Icerik cocuksu veya sig hale gelmedi.
- [ ] Her dersin Depth Ladder bolumu var.
- [ ] Depth Ladder ilerideki kavramlara kisa bag kuruyor.
- [ ] Derinlik ilk ekrani veya ilk anlatimi bogmuyor.

## Cognitive Load

- [ ] Her ders tek ana hedefe odakli.
- [ ] Tek seferde tek fikir korunuyor.
- [ ] Teknik terimler ilk gectiginde sade Turkce aciklaniyor.
- [ ] Micro-assessment tek kavram olcuyor.
- [ ] Soft-check nazik; hard-lock yok.
- [ ] Rescue flow utandirmadan destek veriyor.

## Visual Specificity

- [ ] Her dersin metaforu konuya ozel.
- [ ] Dersler arasi metafor tekrar riski kontrol edildi.
- [ ] Visual Mode jenerik diyagram degil.
- [ ] Visual stage ana ogretim alani olarak tasarlanmis.
- [ ] Visual steps ogrenci kontrollu.
- [ ] Her adim tek fikre odakli.
- [ ] Code-visual sync map var.

## Production / Interview Quality

- [ ] Production example gercek sistemde karsilasilabilir.
- [ ] Debugging perspective belirti, bakilacak yer ve kok neden daraltma iceriyor.
- [ ] Trade-off bolumu alternatif ve bedel gosteriyor.
- [ ] Interview Mode ezber cevap degil, dusunce sirasi veriyor.
- [ ] Follow-up sorusu hedef seviyeye uygun.

## Prerequisite Flow

- [ ] Derslerin on kosul sirasi mantikli.
- [ ] Onceki dersten gelen bridge kisa ve net.
- [ ] Sonraki derse bridge karar yuku yaratmiyor.
- [ ] Eksik on bilgi rescue ihtiyaci not edildi.

## Batch Karari

- [ ] Ders 1: Pass / Patch Needed / Reject
- [ ] Ders 2: Pass / Patch Needed / Reject
- [ ] Ders 3: Pass / Patch Needed / Reject
- [ ] Batch-level minimal patch listesi yazildi.
- [ ] Prototype integration icin hazir / hazir degil karari verildi.
