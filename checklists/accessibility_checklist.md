# Accessibility Checklist

Prototip erişilebilirlik kontrolü.

- [ ] Butonlar native button veya eşdeğer erişilebilir öğe.
- [ ] Tıklama alanları en az yaklaşık 44px.
- [ ] Tab container `role="tablist"` kullanıyor.
- [ ] Tab öğeleri `role="tab"` ve `aria-selected` kullanıyor.
- [ ] Tab panel `role="tabpanel"` kullanıyor.
- [ ] Görsel sahnede kısa `aria-label` var.
- [ ] Canlı değişen kavram panelinde uygun `aria-live` var.
- [ ] Form/radio seçenekleri label ile bağlı.
- [ ] Renk kontrastı sakin ama okunur.
- [ ] Renge tek başına anlam yüklenmiyor.
- [ ] `prefers-reduced-motion` destekleniyor.
- [ ] Klavye ile temel akış kullanılabiliyor.
- [ ] Odak görünürlüğü kaybolmuyor.
