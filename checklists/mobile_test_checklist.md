# Mobile Test Checklist

Gerçek cihaz veya dar viewport kontrolü.

## Cihaz / Viewport

- [ ] iPhone dar ekran veya eşdeğer viewport.
- [ ] Android dar ekran veya eşdeğer viewport.
- [ ] Tablet / orta genişlik.
- [ ] Desktop kontrolü bozulmadı.

## Akış

- [ ] Header taşmıyor.
- [ ] Tab butonları yatay scroll veya wrap ile kullanılabilir.
- [ ] Ders seçimi küçük ekranda anlaşılır.
- [ ] Visual stage aşırı uzun scroll üretmiyor.
- [ ] Sahne içi metinler üst üste binmiyor.
- [ ] Step buttons thumb-friendly.
- [ ] Code panel yatay overflow ile güvenli okunuyor.
- [ ] Assessment seçenekleri rahat seçiliyor.
- [ ] Soft-check mesajı ekranda kaybolmuyor.
- [ ] Placeholder mesajı görünür.

## Hareket / Performans

- [ ] Tekrar İzle hareketi dikkat dağıtmıyor.
- [ ] Reduced motion açıkken hareket bastırılıyor.
- [ ] Görsel sahne boş veya kırpılmış görünmüyor.
