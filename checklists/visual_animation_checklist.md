# Visual Animation Checklist

Görsel sahne ve animasyon kontrolü.

- [ ] Görsel metafor konuya özgü.
- [ ] Jenerik kutu-ok diyagramı değil.
- [ ] Görsel sahne dekor değil, ana öğretim alanı.
- [ ] Her adım öğrenci kontrollü.
- [ ] Tek adımda tek hareket / tek fikir var.
- [ ] Statik kare olarak da anlaşılır.
- [ ] "Tekrar İzle" anlamlı tepki veriyor.
- [ ] Görsel ve aktif kavram aynı şeyi söylüyor.
- [ ] Code Mode varsa satır-görsel senkronu kurulmuş.
- [ ] Renk tek anlam taşıyıcı değil; etiket/şekil de var.
- [ ] Reduced motion desteği bozulmamış.
- [ ] Mobilde sahne okunur ve aşırı uzun değil.
