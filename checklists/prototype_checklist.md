# Prototype Checklist

Prototip entegrasyonu için temel doğrulama.

- [ ] `npm run build` geçiyor.
- [ ] Mevcut dersler bozulmadı.
- [ ] Ders geçişi sakin ve anlaşılır.
- [ ] Her dersin dört tab'ı çalışıyor.
- [ ] Code yalnızca Code tab içinde görünüyor.
- [ ] Visual step kontrolleri çalışıyor: Geri, Sonraki Adım, Tekrar İzle.
- [ ] Side concept panel aktif adımla güncelleniyor.
- [ ] Code highlight aktif adımla senkron.
- [ ] Rescue button çalışıyor.
- [ ] Assessment final step'te görünüyor.
- [ ] Yanlış cevap soft-check tetikliyor.
- [ ] İkinci yanlışta nazik devam izni var.
- [ ] Placeholder mesajı kafa karıştırmıyor.
- [ ] Yeni ders eklenmediyse data listesi değişmedi.
- [ ] Documentation sadece gerekli kısa notları aldı.
