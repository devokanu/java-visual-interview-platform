# Batch Content Storage

This folder stores batch-level content artifacts before they are integrated into the prototype.

## What Goes Here

- Raw batch outputs from Claude.
- Patched batch outputs after review.
- Clean approved Markdown.
- Review reports from Claude, Gemini, or Codex.

## Naming Pattern

- `M0-B01_RAW.md`
- `M0-B01_PATCHED.md`
- `M0-B01_CLEAN.md`
- `M0-B01_REVIEW.md`

## Rules

- Do not store prototype source code here.
- Do not treat stored batch content as integrated lessons until backlog/cursor status says so.
- Keep valid fenced code blocks.
- Keep valid Markdown tables.
- Preserve lesson IDs and titles during cleanup.
